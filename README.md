# 喀纳斯景区 · 步道高程互动地图

以**喀纳斯游客中心（贾登峪）为 0 m** 的相对高程互动地图：覆盖喀纳斯主景区（湖、三湾、观鱼台）、白哈巴、禾木三大区域的全部步道 / 栈道 / 公路，支持两点测线、线路规划与高程剖面图。

## 打开方式

- 直接双击 `web/index.html`（全部数据已内联，无需联网）；或
- 起本地服务后访问 <http://127.0.0.1:8823/>：
  ```bash
  cd web && python -m http.server 8823
  ```

## 功能

| 功能 | 说明 |
| --- | --- |
| 两点测线 | 点击地图设置 A、B，自动沿路网规划徒步线路（Tobler 步行速度 + 路面系数择优，路边投影吸附消除点偏），给出线路图、距离、爬升/下降、高程范围、预计耗时 |
| **途径点** | "＋途径点"后连续点击插入途经位置（W1、W2…），多点规划，支持撤销/删除/交换方向 |
| 高程剖面图 | 交互式图表（悬停联动地图）；采样间隔 12 m |
| 直线剖面 | 各点间按直线剖切地形（越野参考）；路网不连通时自动切换直线参考 |
| **导出** | GPX 轨迹（绝对高程，导入奥维/两步路/手表）、GeoJSON、CSV 高程表（含经纬度）、剖面图 PNG（2×） |
| **区间车线路** | 10 条官方线路（1路主线、观鱼台线、湖边线、一道湾线、新村线、喀纳斯↔白哈巴、铁热克提↔白哈巴、贾登峪↔禾木、禾木换乘、吉克普林接驳），点击线路弹出**站序表**（站名/里程/高程）、沿线机位、沿线高程剖面 |
| 车站/机位 | 54 个车站（官方"游服中心"站名体系）+ 26 个打卡机位（含拍摄建议） |
| 路线详情 | 点击任意道路/步道/湖泊：名称、类型、长度、爬升、高程曲线、湖泊水面高程与面积 |
| 基准切换 | 任意点"设 0 基准"，全部数值即时重算 |
| 推荐线路 | 12 条：三湾栈道、湖边东岸栈道、环湖栈道、观鱼台、禾木晨雾线、官方徒步线 H1/H2 等 |
| 图层/搜索/比例尺 | 7 类图层开关；名称搜索；等距圆柱投影比例尺（无纬度畸变） |
| 景区须知 | 官方徒步开放期（6–8 月）、报备与边境通行证要求、区间车运营季节 |

## 图例约定

- **公路/车道** 橙色实线（带描边）｜**土路/牧道** 棕色虚线｜**步道** 红棕虚线
- **木栈道** 蓝色点线（湖畔/河畔 320 m 内的游步道推断为栈道）｜**台阶** 深棕点线
- **河流/溪流** 蓝色线｜**湖泊** 蓝色面｜**区间车线** 红色长虚线（沿公路网络计算）

## 数据来源与精度

- **路网 / 水系 / 兴趣点**：OpenStreetMap（Overpass API，ODbL）+ 官方公告整理（车站站名、区间车线、徒步线、须知）
- **高程 DEM**：AWS Terrain Tiles（SRTM/AW3D 合成，z13 ≈ 12.6 m/格），沿线每 12 m 采样；公路/土路类做 5 点平滑消除 DEM 阶跃
- **山体阴影底图**：本地由 DEM 自绘渲染（分层设色 + 315° 山体阴影）
- **基准点绝对高程**：1456.8 m（DEM 推算）；图中所有高程均为相对高程
- **位置-高程配准**（重点核验）：用 Sentinel-2 无云影像（WGS84 纠正）对 29 处河道横剖面独立仲裁——S2 与 DEM 一致（差 0.4 m），OSM 河道仅北偏约 10 m（中位），属正常描绘精度，无 30–45 m 级系统偏移（详见 `data/research/offset_check.json`）
- 点击吸附为"路边投影"（点到最近路段的垂足），消除点偏导致的高程跳变；光标高程网格 88 m 双线性
- DEM 纵向误差约 ±10 m；累计爬升/下降按平滑后统计

## 研究与质检附录

- `data/research/trails_research.md`：区间车线路（13 条）、徒步线路（15 条）、官方站名体系与来源
- `data/research/qa_report.md`：路网逐段质检（连通性、断链、坡度异常、覆盖度）
- `data/research/offset_check.json`：S2 影像偏移仲裁原始数据
- 路网缺口以灰色虚线"数据缺口连接"桥接（14 处，寻径代价 ×2.4，弹窗标注）

## 目录结构

```
web/            交互地图（index.html + js + css + data）
  data/kanas_data.js   向量数据 / 路网图 / 高程剖面 / DEM 栅格（自动生成）
  data/hillshade.png   自绘山体阴影底图（自动生成）
data/
  osm/          Overpass 原始数据
  dem/          DEM 瓦片与拼接栅格
  curated.json  基准点、打卡机位文案、推荐线路
scripts/
  fetch_osm.py     抓取 OSM
  fetch_dem.py     抓取并拼接 DEM 瓦片
  process.py       生成 web/data（含路网寻径图、沿线高程、晕渲底图）
  verify_visual.mjs 无头浏览器视觉回归（需本地 http 服务）
gui-test-screenshots/  功能验证截图
```

重新生成数据（改了 `curated.json` 或要更新 OSM/DEM 后）：

```bash
python scripts/fetch_osm.py    # 增量：已存在的文件会跳过
python scripts/fetch_dem.py
python scripts/process.py
```

## 技术说明

- 前端：Leaflet 1.9（本地化，L.CRS.Simple + 公里平面坐标），Canvas 渲染器带 8 px 命中容差，无外部网络依赖
- 寻径：浏览器内 Dijkstra（18,634 节点 / 18,836 边），代价 = Tobler 徒步时间 × 路面系数（步道/栈道 1.0、台阶 1.35、土路 1.18、公路 1.22、缺口连接 2.4），坡度限幅 ±60%
- 高程剖面：路网线路按 12 m 采样拼接；直线剖面用 88 m 栅格双线性插值
- 区间车线：以"公路优先"权重在路网图上求解，站点为 POI 向线路投影（≤150 m）后按里程排序
